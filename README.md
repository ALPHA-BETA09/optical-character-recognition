# optical-character-recognition
# Python Modular OCR System

This is a robust, modular Optical Character Recognition (OCR) system built using Python, OpenCV, and EasyOCR. It extracts text from images, draws bounding boxes around detected text, and saves the results.

## Prerequisites
- Python 3.8+
- Recommended: Create a virtual environment.

1. Clone or download this repository.
